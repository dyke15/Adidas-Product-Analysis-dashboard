
# Adidas Product Analysis Dashboard (Power BI)

## 📊 Overview
This Power BI dashboard analyzes Adidas product sales performance, pricing, and trends across sales channels and time periods.

## 🎯 Business Objective
Help stakeholders:
- Understand product-level performance
- Track total sales and units sold
- Compare sales channels (In-store, Online, Outlet)
- Monitor period-over-period growth

## 🛠 Tools & Skills
- Power BI
- DAX (time intelligence, percentage change)
- Data modeling
- Executive dashboard design

## 📐 Key Metrics
- Total Units Sold
- Total Sales
- Average Price
- Period-over-period % change

## 📈 Insights
- Total units sold reached **245K**, up **8.66%** vs previous period
- Total sales increased by **10.97%**
- In-store sales outperformed online and outlet channels
